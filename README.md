#  Customer Behavior Dashboard

##  Project Overview

This project is an interactive **Customer Behavior Dashboard** developed using **Power BI** to analyze customer purchasing patterns, subscription status, sales, revenue, product categories, age groups, gender, and shipping preferences.

The dashboard transforms customer transaction data into meaningful business insights using **KPIs, interactive filters, and data visualizations**.

##  Objectives

* Analyze overall customer purchasing behavior.
* Compare customers based on subscription status.
* Analyze revenue and sales across product categories.
* Understand purchasing behavior across different age groups.
* Analyze customer demographics such as gender.
* Evaluate different shipping preferences.
* Track average purchase amount and review ratings.
* Build an interactive dashboard for business decision-making.

* Customer ID
* Age
* Gender
* Category
* Purchase Amount
* Review Rating
* Subscription Status
* Shipping Type
* Product Information
* Sales
* Revenue
* Age Group

##  Key Insights

The dashboard helps identify:

1. The overall number of customers and their average purchase value.
2. The percentage of customers who have subscriptions.
3. Which product categories generate the highest revenue.
4. Which categories have the highest sales volume.
5. How purchasing behavior differs across age groups.
6. Which age groups contribute the most revenue.
7. Customer distribution based on gender and subscription status.
8. How different shipping methods relate to customer purchasing behavior.
9. The overall customer satisfaction level through average review ratings.

1. Clone or download this repository.

3. Refresh the dataset if required.
4. Use the interactive filters to explore different customer segments.
5. Analyze sales, revenue, purchasing behavior, and customer demographics.

##  Project Purpose

This project was developed as a **Data Analytics / Business Intelligence portfolio project** to demonstrate the ability to transform raw customer transaction data into an interactive and business-focused Power BI dashboard.

The dashboard provides a clear view of **customer behavior, sales performance, revenue contribution, subscription patterns, demographics, and purchasing trends**, helping businesses make data-driven decisions.
